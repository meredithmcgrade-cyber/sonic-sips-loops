SONIC Sips Menu Loops

Open one page per TV. Each page plays its loop continuously with no black frame between repeats.

Screen 12 min 5 sec loop Screen 21 min 36 sec loop
  1. Open Screen 1 in a Chrome window and drag it onto the first TV.
  2. Open Screen 2 in a second Chrome window and drag it onto the second TV.
  3. Click inside each window once. It goes fullscreen and starts playing.
  4. F toggles fullscreen, R restarts, D shows a debug readout, Esc exits fullscreen.
  5. Turn off sleep and screensaver on the PC so the loops keep running.
